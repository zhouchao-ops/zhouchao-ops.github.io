# Chao Zhou Academic Homepage

This directory contains a complete static academic homepage for GitHub Pages.

## Publish

The GitHub account already has a repository named `zhouchao-ops.github.io`. Replace the files in that repository with the contents of this directory, then commit and push to the `main` branch. GitHub Pages should publish the site at:

https://zhouchao-ops.github.io/

In the repository settings, confirm **Settings → Pages → Deploy from a branch → main / root**.

## Before publishing

- Confirm that the English name of the undergraduate degree should be `B.Eng.`.
- Add a real Google Scholar link when available; the current page intentionally omits it.
- Replace the generated copyright-paper card with an official teaser figure if one becomes available.
- The two downloadable arXiv PDFs are included in `papers/`; the TMLR link opens OpenReview instead.

## Structure

- `index.html` — complete responsive homepage
- `assets/profile/` — profile photo
- `assets/logos/` — institution logos
- `assets/teasers/` — publication preview images
- `papers/` — downloadable public paper PDFs
